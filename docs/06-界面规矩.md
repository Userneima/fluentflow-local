# 界面规矩

FluentFlow 自己的界面写法：用词、各种量怎么写、按钮和颜色、圆角、字号、宽度。换到别的工具产品也成立的规矩（界面只写状态和下一步、状态标签按真实结果、加载时先显示加载中、选中和悬停分得开等）在 skill `tool-product-ui`，这里不重复。2026-10-23 定，2026-10-24 审查后补齐（决策 8.6、8.7）。

能让机器查的几条写在 `frontend/src/ui-rules.test.js`，跑前端测试时一起查，见文末。

## 用词

| 说法 | 指什么 |
| --- | --- |
| 本机文件 | 用系统选择框选的、拖进来认得出位置的文件。FluentFlow 原地读取，不复制（决策 1.7）。拖进来认不出位置、真的复制了一份的那条路叫上传。凡是说「在这台电脑上」，都用「本机」。 |
| 转录 | 把录音变成文字这一步。转录稿、本机转录、重新转录。 |
| 剪后版本、剪后视频 | 剪掉气口后导出的那份。播放、字幕、笔记都按它。原片指用户的原文件，FluentFlow 不改它。 |
| 产出文件夹 | 原片旁边的同名文件夹，里面是剪后视频、笔记 md 和 PDF、「过程文件」。 |
| 处理记录 | 侧边栏那一页，一条录像一条记录。单条的逐步状态叫「处理过程」。 |
| 写笔记 | 让 FluentFlow 写一篇笔记的按钮和动作。重写已有笔记交给 agent。 |
| 剪辑有 N 处需要你判断 | 剪辑里拿不准、等用户定的地方。列表上的短写法是「N 处待你判断」。 |
| 你的 agent | 用户自己的 Claude Code、Codex 这类工具。 |

## 各种量的写法

每种量由 `frontend/src/lib/format.js` 里的一个函数输出，页面直接调用它。

| 量 | 写法 | 函数 |
| --- | --- | --- |
| 一段多长（录像时长、剪掉多少、转录耗时） | 「12 分 43 秒」「3 小时 34 分」，超过一小时写到分；剪辑说明里不到 10 秒的保留一位小数「3.4 秒」 | `fmtDuration(秒, lang, {tenths})` |
| 录像里的一个时间点 | 「03:34」「1:02:05」 | `fmtTime`（转录稿时间戳）、`fmtElapsed`（进度里转录到了哪） |
| 多久以前 | 「5 分钟前」「3 天前」 | `timeAgo` |
| 日期时间 | 「2026-10-23 19:53」 | `fmtDateTime` |
| 文件大小 | 「9.42 MB」「1.1 GB」 | `fmtFileSize`、`fmtBytes` |
| 笔记字数 | 「1734 字」，不加千分位 | `fmtCharCount` |
| 出错原因 | 最多两句：哪里出了问题、怎么处理 | `shortReason(原因, 2)` |
| 模型用的 token | 「8000 token」「12.3 万 token」，一万以下写整数 | `fmtTokens` |
| 模型花的钱 | 按服务商收钱的币种：「¥0.012」「$0.42」，不到一分钱保留两位有效数字；几种币种并排「¥0.021 + $0.40」，不换算 | `fmtMoney`、`fmtCosts` |

## 按钮

样式写在 `frontend/src/lib/ui.js`。每个按钮从那里取样式，自己只加位置、宽度、间距这类布局类。

| 级别 | 样子 | 用在哪 |
| --- | --- | --- |
| 主按钮 `button('primary')` | 深底白字，暗色下白底深字 | 一块区域里最主要的那一个：开始生成笔记、写笔记、对话框的确认、保存 Key。一块区域放一个。 |
| 次按钮 `button('secondary')` | 白底灰边，暗色下浅灰半透明底；悬停底色加深一层 | 其余会做事的按钮：打开文件夹、处理整个文件夹、复制、对话框里的取消。 |
| 弱按钮 `button('quiet')` | 平时只有文字，悬停出现浅灰底 | 一行文字旁边的低频动作。 |
| 危险按钮 `button('danger')` | 白底红边红字 | 取消一个正在跑的任务、取消上传。删除记录放在「⋯」菜单里，用红字菜单项 `menuItem('danger')`。 |
| 图标按钮 `iconButton()` | 方形，只有图标 | 处理记录每条的「打开文件夹」「⋯」、关闭、播放。都带悬停提示和读屏名字。 |
| 文字链接 `linkButton()` | 下划线，颜色跟着所在的句子 | 句子里的动作：处理过程、知道了。设置页「去处理」这类导航用蓝色 `linkButton('blue')`。 |
| 状态按钮 `statusButton()` | 橙色要你判断，红色出了错，灰色在进行 | 能点去处理的状态：剪辑有 N 处需要你判断、笔记没生成。 |

尺寸三档，按位置选：`sm` 高 28 像素、12 像素字，放在列表行、页面顶栏、面板标题栏里；`md` 高 32 像素、13 像素字，放在面板和对话框里；`lg` 高 40 像素、14 像素字，给首页的开始按钮和跟输入框并排的按钮（输入框也是 40 像素高）。

不是按钮的控件也从 `ui.js` 取：

- 一排互斥的选择 `segmentGroup` / `segmentItem`：浅灰底槽，选中的那个浅色下是白块，暗色下是一块更亮的半透明灰。视频链接 / 本机文件 / 字幕文件，文本校对 / 视频复查，关于页的三个页签。
- 筛选和开关 `chip`：选中是深色实心（暗色下白色实心）。全部 / 待你判断，跟随播放。
- 侧边栏 `navItem`：选中的底色更深、字加粗，悬停只浅浅一层。
- 菜单项 `menuItem`，笔记工具栏 `toolbarButton`。
- 整行可点 `rowButton`、`tileButton`、`optionCard`；转录稿时间戳 `timestampButton`；记录里的信息小块 `factBlock`，能点开的那块 `factToggle`；拖放区 `dropZone`。

## 颜色

- 主色是深灰黑 `#111111`，暗色下换成白色，用在主按钮、选中的筛选、选中的侧边栏项。
- 蓝色 `primary` 用在正在播的那一句、选中的选项和导航链接。
- 橙色：要用户判断或结果不完整（N 处待你判断、笔记没生成、只有转录稿）。红色：失败、出错原因、危险操作。绿色用在「已保存」这类一闪而过的反馈。
- 透明度写 5 的倍数（`text-white/60`）或方括号（`bg-white/[0.06]`）。
- `ui.js` 里的白底写成 `bg-[#ffffff]`：`local.html` 用 `.dark .bg-white` 给旧页面统一换暗色底，`ui.js` 的控件要用自己写的暗色和悬停色。

## 卡片和圆角

| 圆角 | 用在哪 |
| --- | --- |
| 16 像素 | 页面上的卡片 `surfaceCard`、直接放在页面上的提示条和出错条，对话框、菜单这类浮层 `floatingLayer` |
| 12 像素 | 卡片和对话框里的一块（`insetBlock`、`cellBase`、卡片里的提示和出错框、转录稿的一段），切换控件的底槽 |
| 10 像素 | 按钮、输入框、筛选、侧边栏项 |
| 8 像素 | 菜单项、信息小块、工具栏按钮、切换控件里的选项、侧边栏收起时的小标志 |
| 6 像素 | 勾选框 |
| 4 像素 | 转录稿里正在改的那一句 |
| 全圆 | 状态标签这类小圆角胶囊 |

页面上的卡片用边框分隔；阴影给浮在页面上的东西：对话框、菜单、悬浮说明、提示消息。

## 字号

- 字体：Inter，中文落到系统的无衬线字体（苹方、冬青黑体、微软雅黑），最后是 `sans-serif`。标题和正文同一套。
- 展示级两处：页面标题 20 像素（设置、关于与协议、处理详情），空状态的主句 18 像素。一页只有一个页面标题用 20 像素。
- 区块和对话框标题 15 到 16 像素（转录原文、笔记正文、最近活动 15 像素；处理详情里的任务名、对话框标题 16 像素）。
- 列表和卡片：处理记录每条的标题 15 像素，卡片标题 14 像素，说明文字 12 到 13 像素。
- 控件：按钮按上面三档；输入框 13 到 14 像素；状态标签 11 到 12 像素。界面上最小的字是 11 像素。
- 内容区按内容定：笔记正文 16 像素（决策 5.34），转录稿 14 像素。
- 字号用固定像素，桌面和窄窗口一套。

## 宽度档

每次改界面在 1440、1024、768 三档下各看一遍，浅色、暗色各一遍。

| 窗口宽 | 侧边栏 | 按钮 | 文字 |
| --- | --- | --- | --- |
| 1440 | 展开，产品名「FluentFlow Local」和副标题一行放得下 | 在行尾 | 记录标题一行放得下就一行 |
| 1024 | 展开 | 在行尾；笔记工具栏收起撤销、重做 | 记录标题最多两行，超出截断、悬停看全名；信息小块换行 |
| 768 | 自动收成图标（「记住的收起状态」保持原样） | 编辑页两栏并排，转录栏顶部的切换挪到标题下一行 | 同上 |
| 不到 700 | 图标 | 处理记录的两个图标按钮挪到标题下一行 | 同上 |

时长、大小、状态这类用户要读的信息换行显示；很长的标题可以截断，截断的带悬停提示看全文。

## 机器查的几条

`frontend/src/ui-rules.test.js`：

- 按钮：每个 `<button>`、带 `role="button"` 的元素、画成按钮样子的链接，样式来自 `lib/ui.js`；旁边只加布局类，不从别的变量带类名进来，不写 `style=`。
- 暗色：`ui.js` 用到的类都不在 `local.html` 的暗色覆盖名单里；次按钮在两种模式下悬停的底色都和平时不同。
- 透明度只用生成得出来的档。
- 圆角只用上表的几档；页面上的阴影只出现在 `fixed`、`absolute` 定位的元素和 `ui.js` 的浮层上。
- 字号不小于 11 像素；Tailwind 配置里每个字体栈以通用字体族结尾。
- 时长只由 `fmtDuration` 写，字数只由 `fmtCharCount` 写，token 数和钱只由 `fmtTokens`、`fmtMoney`、`fmtCosts` 写（数字后面直接跟「秒」「分」「小时」「字」的写法，在模板和 JSX 文本里都查）。
- 中文界面：每个界面文字键都有中文；「Loading」「Untitled」这类词只出现在中英二选一的英文那一边，JSX 文本跨行写也查。
- 用词：「本机」「转录」（匹配服务返回文字的 `.includes` / `.replace` 那几行除外）。

加新规矩时，能写成测试的同时写进去，并配一条「故意写错会被抓到」的用例。
