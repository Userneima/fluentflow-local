# 界面规矩

FluentFlow 自己的界面写法：用词、各种量怎么写、按钮和颜色、字号、宽度。换到别的工具产品也成立的规矩（界面只写状态和下一步、状态标签按真实结果、加载时先显示加载中、选中和悬停分得开等）在 skill `tool-product-ui`，这里不重复。2026-10-23 定（决策 8.6、8.7）。

能让机器查的几条写在 `frontend/src/ui-rules.test.js`，跑前端测试时一起查，见文末。

## 用词

| 说法 | 指什么 |
| --- | --- |
| 本机文件 | 用系统选择框选的、拖进来认得出位置的文件。原地读取，不复制，不叫「上传」「本地文件」（决策 1.7）。只有拖进来认不出位置、真的复制了一份的那条路叫上传。 |
| 剪后版本、剪后视频 | 剪掉气口后导出的那份。播放、字幕、笔记都按它。原片指用户的原文件，FluentFlow 不改它。 |
| 产出文件夹 | 原片旁边的同名文件夹，里面是剪后视频、笔记 md 和 PDF、「过程文件」。 |
| 处理记录 | 侧边栏那一页，一条录像一条记录。单条的逐步状态叫「处理过程」。 |
| 写笔记 | 让 FluentFlow 写一篇笔记的按钮和动作。重写已有笔记交给 agent。 |
| 剪辑有 N 处需要你判断 | 剪辑里拿不准、等用户定的地方。列表上的短写法是「N 处待你判断」。 |
| 本机转录 | 转录在这台电脑上跑。 |
| 你的 agent | 用户自己的 Claude Code、Codex 这类工具。 |

## 各种量的写法

每种量只由 `frontend/src/lib/format.js` 里的一个函数输出，页面不自己拼单位。

| 量 | 写法 | 函数 |
| --- | --- | --- |
| 一段多长（录像时长、剪掉多少、转录耗时） | 「12 分 43 秒」「3 小时 34 分」，超过一小时不写秒；剪辑说明里不到 10 秒的保留一位小数「3.4 秒」 | `fmtDuration(秒, lang, {tenths})` |
| 录像里的一个时间点 | 「03:34」「1:02:05」 | `fmtTime`（转录稿时间戳）、`fmtElapsed`（进度里的已转录到哪） |
| 多久以前 | 「5 分钟前」「3 天前」 | `timeAgo` |
| 日期时间 | 「2026-10-23 19:53」 | `fmtDateTime` |
| 文件大小 | 「9.42 MB」「1.1 GB」 | `fmtFileSize`、`fmtBytes` |

## 按钮

样式只写在 `frontend/src/lib/ui.js`。每个按钮从那里取样式，自己只能加位置、宽度、间距这类布局类。

| 级别 | 样子 | 用在哪 |
| --- | --- | --- |
| 主按钮 `button('primary')` | 深底白字，暗色下白底深字 | 一块区域里最主要的那一个：开始生成笔记、写笔记、对话框的确认、保存 Key。一块区域最多一个。 |
| 次按钮 `button('secondary')` | 白底灰边 | 其余会做事的按钮：打开文件夹、处理整个文件夹、复制、取消。 |
| 弱按钮 `button('quiet')` | 没有底和边，悬停才有浅灰底 | 一行文字旁边的低频动作；对话框里排在最边上的「取消」。 |
| 危险按钮 `button('danger')` | 白底红边红字 | 只给取消一个正在跑的任务、取消上传。删除记录在「⋯」菜单里，用红字菜单项。 |
| 图标按钮 `iconButton()` | 方形，只有图标 | 处理记录每条的「打开文件夹」「⋯」、关闭。必须有悬停提示和读屏名字。 |
| 文字链接 `linkButton()` | 下划线，颜色跟着所在的句子 | 句子里的动作：处理过程、去处理、知道了。蓝色只给设置页的「去处理」这类导航。 |
| 状态按钮 `statusButton()` | 橙色要你判断，红色出了错，灰色在进行 | 能点去处理的状态：剪辑有 N 处需要你判断、笔记没生成。 |

尺寸三档，按位置选：`sm` 高 28 像素、12 像素字，放在列表行、页面顶栏、面板标题栏里；`md` 高 32 像素、13 像素字，放在面板和对话框里；`lg` 高 40 像素、14 像素字，只给首页的开始按钮和跟输入框并排的按钮（输入框也是 40 像素高）。圆角都是 10 像素。

不是按钮的控件也从 `ui.js` 取：一排互斥的选择用 `segmentGroup` / `segmentItem`（灰底里选中的那个是白的：视频链接 / 本机文件 / 字幕文件，文本校对 / 视频复查）；筛选和开关用 `chip`（选中是深色实心：全部 / 待你判断，跟随播放）；侧边栏 `navItem`；菜单项 `menuItem`；笔记工具栏 `toolbarButton`；整行可点的用 `rowButton`、`tileButton`、`optionCard`；转录稿时间戳 `timestampButton`；记录里的信息小块 `factBlock` / `factToggle`；拖放区 `dropZone`。

## 颜色

- 主色是深灰黑 `#111111`（暗色下反过来用白），用在主按钮、选中的筛选、选中的侧边栏项。
- 蓝色 `primary` 只表示「正在播的这一句」「选中的那个选项」和导航链接，不做按钮底色。
- 橙色：要用户判断或结果不完整（N 处待你判断、笔记没生成、只有转录稿）。红色：失败、出错原因、危险操作。绿色只用在保存成功这类一闪而过的反馈，不做常驻标签。
- 写透明度只用 Tailwind 有的档（5 的倍数）或方括号写法：`text-white/60`、`bg-white/[0.06]`。`text-white/62` 这种不生成任何样式，暗色下文字会退回浅色模式的深灰。

## 卡片和圆角

- 页面上的卡片：`surfaceCard`，圆角 16 像素，灰边，没有阴影。
- 卡片里的一块：圆角 12 像素（`insetBlock`、`cellBase`）。
- 只有浮在页面上的东西有阴影：对话框、菜单、悬浮说明（`floatingLayer`，圆角 16 像素）。

## 字号

- 字体：Inter，中文用系统的无衬线字体（苹方、微软雅黑）。标题和正文同一套。
- 展示级只有两处：页面标题 20 像素（设置、关于与协议、处理详情），空状态的主句 18 像素。
- 区块和对话框标题最大 16 像素（转录原文、笔记正文、最近活动 15 像素）。
- 列表和卡片：处理记录每条的标题 15 像素，卡片标题 14 像素，说明文字 12 到 13 像素。
- 控件：按钮按上面三档；输入框 13 到 14 像素；状态标签 11 像素。界面上不出现小于 11 像素的字。
- 内容区按内容定：笔记正文 16 像素（决策 5.34），转录稿 14 像素。
- 不按窗口宽度缩放（不用 `vw`、`clamp()`），桌面和窄窗口一套。

## 宽度档

每次改界面在 1440、1024、768 三档下各看一遍（浅色、暗色各一遍）。

| 窗口宽 | 侧边栏 | 按钮 | 文字 |
| --- | --- | --- | --- |
| 1440 | 展开，产品名「FluentFlow Local」和一句副标题放得下 | 在行尾 | 记录标题一行放得下就一行 |
| 1024 | 展开 | 在行尾；笔记工具栏收起撤销、重做 | 记录标题最多两行，超出截断、悬停看全名；信息小块换行 |
| 768 | 自动收成图标（不改「记住的收起状态」） | 编辑页两栏并排，转录栏顶部的切换挪到标题下一行 | 同上 |
| 不到 700 | 图标 | 处理记录的两个图标按钮挪到标题下一行 | 同上 |

时长、大小、状态这类用户要读的信息只换行不截断，只有很长的标题可以截断，截断的有悬停提示。

## 机器查的几条

`frontend/src/ui-rules.test.js`：

- 每个按钮、画成按钮样子的链接，样式来自 `lib/ui.js`，旁边只加布局类。
- 透明度只用生成得出来的档。
- `lib/format.js` 以外没有手拼的时长（数字后面直接跟「秒」「分」「小时」「min」）；`format.js` 里也只有 `fmtDuration` 写时长。
- 中文界面没有英文占位：每个界面文字键都有中文；「Loading」「Untitled」这类词只出现在中英二选一的英文那一边。
- 用词：不出现「本地文件」「本地上传」「本地转写」。

加新规矩时，能写成测试的同时写进去，并配一条「故意写错会被抓到」的用例。
