# 界面优化清单（2026-10-22 走查）

按四条线分，每条线交给一个对话在自己的工作副本里做。走查在 1440×900 浅色模式下进行，暗色模式和窄窗口没看。

共用约定：界面上的提示只写状态和下一步能点什么，一两句以内；解释放进对话或文档。

## 线一：处理入口和任务列表

处理入口页

1. 顶部叠了两层切换（「视频生成笔记 / 字幕生成笔记」下面再接「链接 / 本机文件」），第一眼要先读懂两层才能开始。合成一层，或让第二层跟着输入内容自动判断。
2. 去「处理记录」有三个入口：侧边栏、卡片右上「查看记录」、最近活动「查看全部」。卡片里的「查看记录」可以去掉。 已完成（2026-10-22）
3. 本机文件拖放区下方有三行说明（原片旁边多一个同名文件夹……），改成一句或去掉；拖放区顶部的上传图标被裁掉了一截。 已完成（2026-10-22）：改成一句「产出放在原片旁边的同名文件夹，原片不动。」，拖进来认不出位置时的提示也压到一句。
4. 最近活动第一次进来时出现过同一任务重复多张、时间乱序（11 分钟前排在 5 天前后面），再进一次正常。需要复现确认。 已完成（2026-10-22）：复现了，浏览器控制台报同一个 key 重复。根因是每条记录的 id 取生成时的 `Date.now()`，同一毫秒生成的几条 id 相同，列表从缓存换成最新数据时 React 重复、漏掉卡片。改用任务编号。
5. 最近活动每张卡都挂「已完成」，信息量为零；只在进行中、失败、需要判断时显示状态。 已完成（2026-10-22）
6. 卡片的渐变光斑背景对工具页没有帮助，可去掉。 已完成（2026-10-22）

处理记录页

7. 顶部三张统计卡（进行中 0、排队中 0、历史记录）占一整行。历史记录数字随滚动加载从 100 跳到 134，不是真实总数。合成一行小字，只在有进行中或排队时突出。
8. 每条记录卡片很高，一屏只放得下两三条；产出路径整条全写出来。压成紧凑列表，路径收进「打开文件夹」。
9. 去气口没成功、笔记没生成的任务也挂绿色「已完成」。和待办里「已完成的含义」那条是同一个问题，一起做。 已完成（2026-10-22）：界面按真实结果标「笔记没生成 / 只有转录稿 / 没去成气口 / N 处待你判断」，橙色；后台状态没动，见待办。
10. 「有 N 处需要你判断」只在处理记录卡片里展开能看到，点「查看结果」进编辑器后找不到这几处。要么编辑器里也有入口，要么这个提示直接带你去要判断的地方。 处理记录这一侧已完成（2026-10-22）：「查看结果」打开 `/editor?task=<任务编号>`，有待判断时再加 `&review=cut`。编辑器里读这两个参数、显示这几处由线二做。
    - 编辑器这一侧已完成（2026-10-22）：标题下面有「剪辑有 N 处需要你判断」，点开就地处理。处理记录要直接带人去判断时，跳 `/editor?task=<任务编号>&review=cut`，进来就打开处理说明。
11. 卡片里的处理说明数字对不上：卡片写「剪掉 1887 处」，展开的说明分组加起来只有几十条。 已完成（2026-10-22）：卡片只写剪掉多长时间，不写处数。
12. 时长写法不统一：「12min43s」「11m 24s」「3:34:38」「02m28s」混用，统一成一种。 已完成（2026-10-22）：统一为「12 分 43 秒」「3 小时 34 分」（`lib/format.js` 的 `fmtDuration`），录像里的时间点仍是钟点写法。编辑器顶部「转录耗时」跟着变。
13. 一百多条记录没有搜索和筛选（比如只看需要判断的、只看失败的）。
14. 每条都放着「删除记录」，和「查看结果」并排、同样显眼。收进更多菜单。 已完成（2026-10-22）
15. 兜底提示句子绕：「没有等到 agent 的剪辑判断（你在网页上选了让 FluentFlow 自己判断），由 FluentFlow 自己判断。」改成一句状态。 已完成（2026-10-22）：「剪辑由 FluentFlow 判断（你选的）。」或「agent 的对话已经关掉了，剪辑改由 FluentFlow 判断。」

处理详情页

16. 已完成的任务还显示「当前阶段 已完成 100%」和整条进度条，去掉。 已完成（2026-10-22）
17. 橙色说明里全是分贝、0.3 秒、1029 处这类判断过程，而且和上面的 501 处对不上。界面只留结果。 已完成（2026-10-22）：只写剪掉和剩下多长。
18. 在这一页时侧边栏高亮的是「编辑器」，应该是「处理记录」。 没复现（2026-10-22）：直接打开和从编辑器跳过来，高亮的都是「处理记录」，代码也按网址判断。选中底色 `#e8e5e5` 和悬停底色 `#efeeee` 几乎分不出，走查时多半是鼠标停在「编辑器」上。选中状态做得更明显放进最后的统一视觉一轮。
