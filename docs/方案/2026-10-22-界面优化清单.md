# 界面优化清单（2026-10-22 走查）

按四条线分，每条线交给一个对话在自己的工作副本里做。走查在 1440×900 浅色模式下进行，暗色模式和窄窗口没看。

共用约定：界面上的提示只写状态和下一步能点什么，一两句以内；解释放进对话或文档。

## 线一：处理入口和任务列表

处理入口页

1. 顶部叠了两层切换（「视频生成笔记 / 字幕生成笔记」下面再接「链接 / 本机文件」），第一眼要先读懂两层才能开始。合成一层，或让第二层跟着输入内容自动判断。
2. 去「处理记录」有三个入口：侧边栏、卡片右上「查看记录」、最近活动「查看全部」。卡片里的「查看记录」可以去掉。
3. 本机文件拖放区下方有三行说明（原片旁边多一个同名文件夹……），改成一句或去掉；拖放区顶部的上传图标被裁掉了一截。
4. 最近活动第一次进来时出现过同一任务重复多张、时间乱序（11 分钟前排在 5 天前后面），再进一次正常。需要复现确认。
5. 最近活动每张卡都挂「已完成」，信息量为零；只在进行中、失败、需要判断时显示状态。
6. 卡片的渐变光斑背景对工具页没有帮助，可去掉。

处理记录页

7. 顶部三张统计卡（进行中 0、排队中 0、历史记录）占一整行。历史记录数字随滚动加载从 100 跳到 134，不是真实总数。合成一行小字，只在有进行中或排队时突出。
8. 每条记录卡片很高，一屏只放得下两三条；产出路径整条全写出来。压成紧凑列表，路径收进「打开文件夹」。
9. 去气口没成功、笔记没生成的任务也挂绿色「已完成」。和待办里「已完成的含义」那条是同一个问题，一起做。
10. 「有 N 处需要你判断」只在处理记录卡片里展开能看到，点「查看结果」进编辑器后找不到这几处。要么编辑器里也有入口，要么这个提示直接带你去要判断的地方。
11. 卡片里的处理说明数字对不上：卡片写「剪掉 1887 处」，展开的说明分组加起来只有几十条。
12. 时长写法不统一：「12min43s」「11m 24s」「3:34:38」「02m28s」混用，统一成一种。
13. 一百多条记录没有搜索和筛选（比如只看需要判断的、只看失败的）。
14. 每条都放着「删除记录」，和「查看结果」并排、同样显眼。收进更多菜单。
15. 兜底提示句子绕：「没有等到 agent 的剪辑判断（你在网页上选了让 FluentFlow 自己判断），由 FluentFlow 自己判断。」改成一句状态。

处理详情页

16. 已完成的任务还显示「当前阶段 已完成 100%」和整条进度条，去掉。
17. 橙色说明里全是分贝、0.3 秒、1029 处这类判断过程，而且和上面的 501 处对不上。界面只留结果。
18. 在这一页时侧边栏高亮的是「编辑器」，应该是「处理记录」。

## 线二：编辑器左侧（转录稿、剪辑、顶部操作栏）

不碰右侧笔记区，那块由 Obsidian 编辑器样机分支在改。

1. 转录稿一句一行、每行配时间戳，碎句（「然后一些」「我觉得大家」）占满屏幕，读起来很费劲。按停顿或讲话人合成段落，时间戳只在段首。
2. 这条是「说话人区分试验」，但转录稿里看不到说话人。
3. 顶部条里「播放、字幕、笔记都是这一份剪后版本；原文件没有被改动」是解释，去掉。
4. 顶部操作按钮五个并排（更换提示词、重生笔记、重新转录、导出到飞书、固定），「重生笔记」用词别扭，「固定」看不出固定什么。把不常用的收进更多菜单。
5. 「视频复查」切过去视频框是黑的，切换按钮的选中状态看不出来。
6. 编辑器网址里没有任务编号，刷新或从别处返回可能丢掉当前任务，也没法收藏某一条。
7. 页面加载时显示英文「Loading...」。

## 线三：设置和接入

1. 设置页围绕各家 Key 展开，但实际写笔记的是本机登录的 Claude 订阅，这件事只在副标题里一句带过。把「现在谁在写笔记、谁在判断剪辑」放到最上面，Key 退到「换一种方式」里。
2. 页面刚打开时 Key 显示「未配置」、多出一个通义千问的 Key 栏，加载完才变成「已配置」。加载前应显示加载中，不先显示错的状态。
3. 「笔记」这一节开头写的是「转录在本机完成，不需要 Key」，说的是转录，放错了位置。
4. 每个 Key、看图模型的地址 / Key / 模型名各有一个保存按钮，看图模型一项就三个。改成整节一个保存或失焦自动保存。
5. 几乎每项下面都有两三行说明（比如看图模型那段带了完整地址和模型名示例），压到一句，细节放「了解更多」。
6. 服务商下拉里标着「通义千问（推荐）」，选中的却是 DeepSeek，推荐标记该跟着实际情况走或去掉。
7. 「导出记录」放在设置页里，它是历史数据，不是设置；挪到处理记录或去掉。
8. 设置页很长，没有分节跳转。
9. 「Agent 接入」藏在左下角菜单里，第一步要求填访问令牌，本机单用户时这一步通常不需要；也看不出现在有没有 agent 已经连上。
10. 版本更新页写着「更新来源 docs/03-更新记录.md」，正文里有环境变量名，这是写给开发者的；「最后更新」日期比最新一条记录早。
