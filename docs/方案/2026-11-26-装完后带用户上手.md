# 装完后由 agent 带用户上手

2026-11-26 王愉超提出并定下方向。

## 要做到什么

用户装好 FluentFlow 之后，agent 按我们写好的步骤一步步带他用一次：先问他最想用它做什么，再用他自己的素材做一遍，让他看着需求被满足，而他只是说几句话、打几个字。整条自动化流程要做得够顺，这次上手就是验收。

## 流程

用户每步只说一句话或选一个号。

1. 装完马上问：「你下载 FluentFlow 最想用它做什么？」给六个选项（王愉超 2026-11-26 定）：
   1. 网课、讲座视频 → 能跟着学的笔记（带截图、分章节，点一下跳回视频那一段）
   2. 抖音、B 站、YouTube 收藏的视频 → 能直接看的文字笔记
   3. 会议、访谈的录音录像 → 逐字稿和整理好的纪要
   4. 只要逐字稿或字幕
   5. 剪掉录音里的空白和气口，顺便压小体积
   6. 其他（说说你的情况）
2. 「给我一个你手上的视频或链接」。手上没有时，请他随便找一个抖音视频的分享链接贴过来（王愉超 2026-11-26 定，不内置样例）。
3. agent 全程代办，每步一句话告诉用户在做什么、他什么都不用做。
4. 交付：打开笔记和剪好的视频，对着他选的需求说明满足了什么，再加一句他这次只打了几个字。
5. 按他选的需求带他试两三个只要说话就能做的事：「这句写错了，改成……」「以后都这样写」「给我出一份复习笔记」「发到飞书」「学完了」。
6. 收尾：以后把视频或链接丢给 agent 就行。

## 放在哪

- 记下这台机器带过没有，带过就不再带。

## 待核实

- 刚装完的那个对话里 agent 还用不了 FluentFlow 的工具（工具在下一个对话才出现）。先实测 Claude Code、Codex 能不能在同一个对话里装完就用；不能的话，第 1 步在安装对话里问完、记下选择，请他开新对话说一句「开始」，新对话接着带。

- Gemini 4 Hydrogen 独立出的流程和每步话术（2026-11-26，只读子对话「上手引导：独立方案和每步话术」，原文在 T3 那个子对话里）提出的三处要核实，都还没核：
  - 新对话里用户只说「你好」「开始」、没带视频时，agent 可能不会读 FluentFlow 的 skill（它的说明写的是给了视频或链接时才用），引导就触发不了。
  - 刚装完的第一条正赶上后台在下语音识别模型（1.5 到 3 GB），agent 按规矩等待时不说话，用户会以为卡死了；要看等待返回能不能区分「在下模型」和「在转录」，第一次下模型时报一句进度。
  - 选「剪空白、压体积」时，不剪的压缩版只在 Mac 上用硬件编码出，Windows 和纯音频不出，要在交付时如实说。
- 它的流程和我们的一致处：装完在安装对话里交接、新对话一气走完；用户理想情况只打三次字（选号、给素材、收尾）；跳过选号直接丢素材的不拦，照做；这台机器跑出过一条真实任务就不再带。

## 验收

在隔离的沙箱里，让全新的 agent（Claude Code、Codex 各一次）扮演从零开始的用户，从安装走到拿到笔记，记下用户打了几次字、用了多久、哪步卡住，改到顺为止。
