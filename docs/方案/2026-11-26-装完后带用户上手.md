# 装完后由 agent 带用户上手

2026-11-26 王愉超提出并定下方向。

## 要做到什么

用户装好 FluentFlow 之后，agent 按我们写好的步骤一步步带他用一次：先问他最想用它做什么，再用他自己的素材做一遍，让他看着需求被满足，而他只是说几句话、打几个字。整条自动化流程要做得够顺，这次上手就是验收。

## 流程

用户每步只说一句话或选一个号。

1. 装完马上问：「你下载 FluentFlow 最想用它做什么？」给六个选项（王愉超 2026-11-26 定）：
   1. 网课、讲座视频 → 能跟着学的笔记（带截图、分章节，点一下跳回视频那一段）
   2. 抖音、B 站、YouTube 收藏的视频 → 能直接看的文字笔记
   3. 会议、访谈的录音录像 → 逐字稿和整理好的纪要
   4. 只要逐字稿或字幕
   5. 剪掉录音里的空白和气口，顺便压小体积
   6. 其他（说说你的情况）
2. 「给我一个你手上的视频或链接」。手上没有时，请他随便找一个抖音视频的分享链接贴过来（王愉超 2026-11-26 定，不内置样例）。
3. agent 全程代办，每步一句话告诉用户在做什么、他什么都不用做。
4. 交付：打开笔记和剪好的视频，对着他选的需求说明满足了什么，再加一句他这次只打了几个字。
5. 按他选的需求带他试两三个只要说话就能做的事：「这句写错了，改成……」「以后都这样写」「给我出一份复习笔记」「发到飞书」「学完了」。
6. 收尾：以后把视频或链接丢给 agent 就行。

## 放在哪

- 装好后 agent 读的说明（`AGENT_INSTALL.md`「Tell the user how to use it」、`agent/skills/fluentflow/SKILL.md`）加一节「第一次使用」，选项和每步说的话写死在那里。
- 记下这台机器带过没有，带过就不再带。

## 装完的那段对话能不能直接用工具（2026-11-26 实测，记录在 `private/测试记录/2026-11-26-上手引导调研/`）

- 同一段对话里用不上：Claude Code 和 Codex 都只在会话开始时载入工具，装完后注册的工具这段对话里调不到（Claude Code 交互界面的 `/mcp` 也只提示要重启）。
- 接着这段对话换个新进程就能用，前面说的话都在：Claude Code 退出后输入 `claude --continue`，Codex 退出后输入 `codex resume --last`。沙箱里用真实的 FluentFlow 验过：接回安装那段对话后直接调到了 `get_status`。
- 所以做法定为：agent 在后台跑安装的那 15 到 30 分钟里就问完第 1 问（六选一）和第 2 问（素材或抖音链接）；装完只请用户退出、输入一条接着聊的命令，进来直接开始处理。FluentFlow 的 skill 也是开场才载入，所以前两问要写进 `AGENT_INSTALL.md` 本身。
- 桌面 App、IDE、T3 这类没法「接着聊」的：安装对话把选择记下来，请用户开新对话说一句写死的话（比如「带我用一次 FluentFlow」），这句写进 skill 的说明好让它被认出来。光说「开始」认不出。
- 记录放在现有的 `fluentflow_config.json` 里加一节 `first_use`（带过没有、选了哪个需求、给的素材），`get_status` 带出来；一个任务都没有的机器才算没带过，老用户更新后不会被拉去重新上手。

## Gemini 独立方案提出的要核实处

Gemini 4 Hydrogen 独立出的流程和每步话术（2026-11-26，T3 只读子对话「上手引导：独立方案和每步话术」）和这里一致的：用户理想情况只打三次字（选号、给素材、收尾）；跳过选号直接丢素材的不拦，照做。它提出、还没核的：
- 刚装完的第一条正赶上后台在下语音识别模型（1.5 到 3 GB），agent 等待时不说话，用户会以为卡死了；要看等待返回能不能区分「在下模型」和「在转录」，第一次下模型时报一句进度。
- 选「剪空白、压体积」时，不剪的压缩版只在 Mac 上用硬件编码出，Windows 和纯音频不出，交付时如实说。

## 调研时查出的两个安装问题

- `install.sh` 给 Codex 注册工具时没带端口（Claude Code 那份带了），端口不是 8000 的用户在 Codex 里会连到 8000。
- 生成桌面图标失败时整个安装中断，工具注册和启动都被跳过；沙箱里撞到过一次（`osacompile` 写不进桌面）。

## 验收

在隔离的沙箱里，让全新的 agent（Claude Code、Codex 各一次）扮演从零开始的用户，从安装走到拿到笔记，记下用户打了几次字、用了多久、哪步卡住，改到顺为止。被测 agent 要一直开着同一个进程，只在模拟用户照 agent 说的去「退出再接着聊」时重启，否则测不出装完要重开这一步。脚手架草稿在 `private/测试记录/2026-11-26-上手引导调研/harness.py`；安装那半试跑过一次（约 4 分钟）。估计每种 agent 一轮 20 到 30 分钟。
