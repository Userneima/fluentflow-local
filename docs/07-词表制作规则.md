# 词表制作规则

词表就是 FluentFlow 的校正文档：一份 `FluentFlow 校正文档.md`，写着某一类录像里转录常听错的名字和说法。写笔记时 FluentFlow 把它交给写笔记的模型，模型照着写对，不再标「（存疑）」。人或 agent 照下面的规则就能做一份、补一条，也能把做好的词表直接给别人用。

词表靠积累：每处理一条录像、每改一次听错的词，就补进去。现阶段由王愉超积累（2026-10-25 定）。

## 放在哪

- 文件名固定为 `FluentFlow 校正文档.md`，放在录像所在的文件夹，或它上面任意一层（到用户主目录为止）。
- FluentFlow 从录像所在的文件夹往上找，**只读找到的第一份**，超过 4000 字的部分不读。
- 一类话题一份（例如 AI 大模型的访谈和课程），放在这类录像共同的上层文件夹。某个系列另有专门的词（一个团队周会的人名），在那个系列的文件夹放一份，同时把它要用到的话题词也抄进来，因为下层那份会挡住上层的。

## 什么词进词表

同时满足这三条才进：

1. **转录真的写错过**：在某条录像的转录稿里见过错的写法。转录本来就写对的词不进。
2. **会再出现**：这一类录像里还会说到的名字、产品、模型、公司、英文术语和缩写、带单位的固定说法（「1T」「10B」「一兆上下文」）。只出现一次的不进。
3. **正确写法核实过**：画面上的字幕或幻灯片、官方页面、本人听录像确认，三者有一个就行。拿不准的不进，留在笔记里标「（存疑）」。

词从哪里找：

- 笔记里你改掉的「（存疑）」：改前那个词就是听法，改后就是正确写法。
- 画面字幕修正的记录：agent 用 `list_subtitle_corrections` 能列出每处从什么改成什么，反复出现的那些进词表。
- 讲座或访谈的标题、简介、章节栏里的名字，**只在转录稿里确实写错了时**才进。

## 每条怎么写

一行一条，格式和现有的校正文档一致：

```
- 正确写法：是什么，一句话（属于哪家公司或哪个领域）。转录常听成：听法1、听法2
```

- 正确写法用官方的大小写和连字符（GLM-5、MiMo-V2、loss spike）。
- 「是什么」只写一句，够写笔记的模型分清同名的东西就行。
- 听法照转录稿原样抄，包括大小写和中英混写（OpenCloud、open cloud、Cloud Code），多种都列上。
- 按类分小节：名称（人、公司、产品、模型）、术语、数字说法。每节里常出现的排前面。
- 文件开头一句写清这份管哪类录像。

## 什么时候补、怎么删

- 每读完一篇笔记、改过听错的词，当场补进去；同一个词又被听成新的样子，把新听法加到那一条后面。
- 快到 4000 字时，删掉最近几个月的录像里没再出现的条目。
- 发现某条写错了，直接改掉，不留旧写法。

## 分享

- 话题词表只写公开的名字和术语，可以直接把文件发给别人，对方放进自己对应的文件夹就能用。
- 合并别人的词表：按正确写法去重，听法合在一起。
- 团队周会这类系列词表里有同事的名字，不外传。
