# 交付记录

主对话把一块活交给另一个对话做（计划里的一条线、一个子对话任务）时，那块活在这里留一份记录，文件名 `YYYY-MM-DD-<主题>.md`，写法照 `subsession-acceptance` skill（王愉超，2026-10-22）：

- 子对话的交付说明，主对话独立审查后加的验收一节，以及存档对话的文件名（可读的 Markdown 记录）。存档对话放在仓库外的 `~/9.归档/对话存档/fluentflow-local/`。
- 改动前后的截图放 `docs/images/`，从记录里链过去。
- 计划文档把每条线链到它的记录；验收后的后续工作另写一份，从原记录链过去。
- 记录留着，不删。
