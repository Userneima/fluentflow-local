- 新模块 `backend/core/glossary_correction.py`（要求 1、2、3）：
  - 模型按顺序读整条转录稿，每次约 3000 字、前后各带 6 句只读的上下文，系统提示里带上录像所在系列的词表（`correction_notes.for_task`，没有词表时写明只能靠上下文）。模型给出每处「原词、改成、依据（glossary / context）、一句理由」。
  - 程序把关：沿用画面字幕修正的边界（`subtitle_correction._acceptable`：被换部分最多 6 个字词、长短差有限、不加原句没有的括号、只差大小写不算、原词必须在句中）；同一词在句中出现多次时模型要给出第几处，给不出不改。改成的写法是词表里某一条（英文要是完整的词）才记为按词表，并记下那一行；其余算按上下文，没有理由的不收。
  - 每处记录：id、时间、原词、改成、在句中的位置、依据和词表那一行或理由、改前改后整句；列表时附上它现在是第几句（那句被改过就是 null）。
  - 撤回一处或全部：复用画面字幕修正的撤回（改成可指定记录字段），转录稿的每一份副本（raw、display、corrected、source_*）一起改回。
- 用户改过的句子不动（要求 7）：FluentFlow 写转录稿时给每句记一个指纹（`transcript_fingerprints`），流程、纠正、撤回都会补记；重跑时指纹对不上的句子算用户的，不改。上线前的老任务没有指纹，只能按编辑页存的修改记录认。画面字幕修正的撤回同时改成：页面上那句被用户改过，就哪份副本都不动、报找不到。
- 流程（要求 4、5）：`media_job` 在画面字幕修正之后、写笔记和剪辑判断之前加一步「正在按词表和上下文改正听错的名字和术语」。模型选法和字幕修正一样（开了订阅先用订阅，运行中失败换用设置里的 Key）；模型报错整步记失败写原因，不重问；回复读不出再问一次；取消能停；任何情况都不让任务失败。`FLUENTFLOW_GLOSSARY_CORRECTION=off` 关掉。剪辑后记录的时间跟着换到剪后视频的时间（`survey_cut`）。
- 旧的 `transcript_correction.py` 删掉（要求 5）：它默认关、只走 DeepSeek、不读词表、整句改写进一份只给笔记读的副本，和新做法完全重叠，留着就是第三套。老任务里它留下的 `corrected_segments` 仍被撤回和剪辑换算照顾到；`FLUENTFLOW_TRANSCRIPT_CORRECTION*` 不再读。
- 已有任务（要求 6）：HTTP `GET /agent/v1/tasks/{id}/glossary-corrections`、`POST …/run`、`POST …/revert`，MCP 工具 `list_glossary_corrections`、`run_glossary_correction`、`revert_glossary_corrections`。重跑在任务还在处理、已经在重跑时拒绝；跑的过程中转录稿被改过就不写入（409 `transcript_moved`）。写入后字幕文件重写，产出文件夹约一分钟后跟着更新。

### 4. 经验

- 被纠正过的做法：词表归类按「改成的写法包含在词表那一行里」判断，会把 Codex 算成 code、Agent 算成 subagent；改成英文要是完整的一个词。落点：本项目，已写进决策记录 4.15 和代码注释。
- 实测数字：整条 1165 句、约 1.1 万字的转录稿，订阅 4 次调用、37 秒；改动约每 10 句一处，按词表和按上下文各一半。落点：本项目，决策记录 4.15。
- 产出文件夹在保存后静默 60 秒才刷新，验证时要等一分多钟再看。落点：本项目，测试记录里写了；代码里本来就有说明。
- 跨项目：`pytest … | tail -1 && git commit && git push` 这种串法，管道把测试的退出码吃掉了，测试失败照样提交推送（这次推上去的那个提交测试其实是过的，挂的是偶发的那条）。要拦就用 `set -o pipefail` 或不接管道。
- 跨项目：同一个模型、同一份输入跑两次，结果会有一成多不同；抽查、准确率这类数字只代表抽的那一次，报告里要写明是哪一次，重跑后要重抽。

- 本项目：反复跑测试时，测试进程退出那一刻 onnxruntime 自带的遥测上报线程会崩溃（报告里是 `Microsoft::Applications::Events` 线程锁互斥量失败），macOS 每次弹「Python 意外退出」。2026-10-25 循环跑测试时王愉超连着看到好几次。跑测试循环前要知道这会打扰他；根治办法是在导入 onnxruntime 后关掉它的遥测（`onnxruntime.disable_telemetry_events()`），没做，记在这里。落点：本交付记录；要做的话进待办。
