## 交付单

### 1. 改了什么

1. 入口页两层切换合成一排：视频链接、本机文件、字幕文件（a23f645）
2. 去掉卡片右上的「查看记录」（e0f1713）
3. 拖放区下面的三行说明改成一句，上传图标不再被裁；拖进来认不出位置时的提示也压成一句（e0f1713）
4. 最近活动重复、乱序：复现到了。每条记录的 id 用的是生成时的毫秒时间戳，同一毫秒生成的几条 id 一样，列表从缓存换成最新数据时 React 会重复或漏掉卡片。改用任务编号（e0f1713）
5. 最近活动里正常完成的任务不挂状态（e0f1713）
6. 去掉渐变光斑背景（e0f1713）
7. 三张统计卡改成筛选按钮，带数量，读到完整列表后才显示总数。数字从 100 跳到 134，原因是先显示浏览器缓存的 100 条，不是滚动加载；有任务在跑时才出现「N 个在处理」（a23f645）
8. 记录压成两行；产出路径收进「打开文件夹」按钮的悬停提示；处理说明收进「…」菜单（a23f645）
9. 状态按真实结果显示：笔记没生成、只有转录稿、没去成气口、N 处待你判断，都用橙色。后台状态没改（e0f1713）
10. 「查看结果」打开 `/editor?task=…`，有待判断剪辑时再带 `&review=cut`，和线二的参数一致（e0f1713）
11. 卡片只写剪掉多长时间，不写剪掉几处（e0f1713）
12. 时长统一用 `fmtDuration`，写成「12 分 43 秒」「3 小时 34 分」；编辑器的「转录耗时」通过 editor-helpers 跟着变（e0f1713）
13. 按标题搜索，加筛选：全部、进行中、待你判断、有问题（a23f645）
14. 「删除记录」收进「…」菜单，删除前仍会确认（e0f1713）
15. 兜底提示改成一句状态（e0f1713）
16. 已完成任务的详情页去掉阶段和进度条（e0f1713）
17. 详情页的去气口说明只写剪掉多长、剩多长，去掉分贝、阈值、抽查警告和处数（e0f1713）
18. 没复现，见第 3 项

### 4. 经验

- 只关 FluentFlow：在工作副本里用自己的端口跑开发服务器、连 8000 的真实数据看界面，不重启服务，只看不点会改数据的按钮。已写进 `docs/04-维护手册.md`（2ee983b）。
- 只关 FluentFlow：状态标签和时长写法，已写进 `docs/02-决策记录.md` 6.23；待办「已完成的含义」下注明界面这一侧先做了。
- 跨项目：列表的 key 不能用生成时的 `Date.now()`，同一毫秒生成的几条会撞 key，表现为重复卡片、顺序错乱，重新打开又好了。用稳定的业务 id。
- 跨项目：选中色和悬停色太接近时，走查会把悬停误报成「高亮错了」。选中状态要和悬停明显区分；报导航高亮问题之前，先用 DOM 或代码确认。
- 跨项目：卡片上的数和展开后的明细数口径不一样时，卡片换一个对得上的口径，不并排摆两个对不上的数。
