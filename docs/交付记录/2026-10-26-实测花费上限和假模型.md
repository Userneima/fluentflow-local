## 3. 没做的、没验证的

- 真实数据上的假模型那一条没走到判断结尾、画面字幕修正、翻译、对齐分段时间、复习笔记：这条录像的流程不触发它们（中文、没烧字幕、分段时间默认关、复习笔记要另外让 agent 写）。这几类只在 pytest 里验证过格式能被解析。
- 下载转录模型时 huggingface 的检查请求不受假模型管：它不是模型调用，假模型只管调用模型的出口。
- 花费在调用结束后才知道，金额上限可能被最后一次调用超出一点，维护手册写明了。

## 4. 这次得出的经验

- 只关这个项目：一种币种的上限只拦这种币种的服务商（实测时 0 元上限把 Claude 也拦了才发现）——写进了决策 8.12。
- 只关这个项目：在工作副本里起服务时前端还没构建，页面的静态文件没挂上，打开是空白页；先构建再起服务——写进了维护手册「在真实数据的副本上实测」一节。
- 只关这个项目：几份老测试在主线程上开步骤不复位，「当前任务」会漏进后面的测试——用 `tests/conftest.py` 的夹具守住了。
- 跨项目：在真实数据的副本上起完整服务实测前，先查服务启动时会开的后台任务（监视文件夹、和云端同步）。副本里的记录还指着真实文件和云端文档，这些后台任务会改到原件。这次给 FluentFlow 加了 `FLUENTFLOW_TEST_COPY` 关掉它们。

## 5. 要用户拍板的事

- 脚本默认的预算是 40 次调用、1 美元、1 元。我倾向保留：一条 4 分钟片段测效果按 API 价约 0.6 美元（10-25、10-26 的实测），够跑一次，跑第二次就会被拦下。
