## 1. 改了什么

对应需求：交给 agent 的任务（`intelligence=agent`），画面字幕修正、词表纠错、英文字幕翻译三步原来记 `agent_required` 跳过；现在由 agent 取材料、判断、交回，结果和后台做出来的一样落到转录稿和字幕。

- 新文件 `backend/core/agent_correction.py`：哪些步骤留给了 agent（`pending`）、分页材料（`material`）、交回（`save`）。`step` 分 `subtitles`、`glossary`、`translation`；按固定句子范围分页（400 / 300 / 200 句），每页自己的版本号。画面字幕第一次取材料时在本机后台线程读出，存在任务产物目录的 `agent_subtitle_track.json`。
- 需求「用户改过的句子不能盖掉」：字幕材料不给这些句子，词表材料标 `locked`，交回针对它们的改动不收。
- 需求「取材料带版本号，期间变了拒绝成 stale、什么都不写」：页的版本只看这一页的句子、谁改过和句子总数；写入时在同一事务里再核一次。
- 需求「每处修正记录、能用现有工具单独撤回、记下是 agent 和模型」：改动写进原来的 `subtitle_corrections`、`glossary_corrections`，带 `by=agent`、`model`；agent 交回的改动和模型的过同一道检查，从原判断里抽出 `subtitle_correction.held_to_picture`、`glossary_correction.held_to_bounds` 共用。
- 需求「剪后时间轴字幕、导出 srt、跟随播放照旧对得上」：写入走 `glossary_correction.onto_result`（加了 `field` 参数）和 `_attach_result_artifacts`，和已完成任务重跑词表纠正同一条路；翻译写 `display_segments`，剪过的任务另存原片时间上的 `source_display_segments`。
- 需求「`wait_task` 在合适的时候提示」：任务做完时 `wait_task` 的 `next` 按流程顺序点名还没做的步骤，排在写笔记、对齐之前（有写到一半的笔记先接着写）；`get_task` 加 `agent_corrections_left`，任务包 `next_actions` 第一条指向取材料。
- 需求「已处理过的任务也能补做」：任意已完成任务都能取材料、交回；不主动提醒。
- 接口：路由 `POST /agent/v1/tasks/{id}/agent-correction/material`、`POST /agent/v1/tasks/{id}/agent-correction`；MCP 工具 `get_agent_correction_material`、`save_agent_correction`。
- 文档：`agent/skills/fluentflow/SKILL.md`（新节「Correcting the transcript yourself」，做笔记步骤加第 3 步）、MCP 工具说明、`AGENTS.md`「Where things are decided」、README、`AGENT_INSTALL.md`、`docs/04-维护手册.md`、决策 4.16、更新记录；`docs/01-待办.md` 那一条改成只剩复习笔记的 agent 入口。

## 3. 没做的、没验证的

- 没在副本里的旧任务上实测：副本按设计拒绝对旧任务的一切写请求，改用从真实录像剪出的新任务。
- 长录像的多页没实测：两个片段都只有一页，分页和「存一页不让下一页过期」只由单元测试覆盖。
- 边导出剪后视频边写的笔记会先于修正写好，没有改：任务在跑时写进去的修正会被流程盖掉，修正只能等任务做完；agent 被告知去改笔记里的错词或提议重写。
- 翻译没有撤回工具：后台翻译也没有，重翻那一页就替换。
- 产出文件夹不放双语 srt：后台翻译的任务也只放原文 srt 和 txt，没改这个行为。
- 没重启 8000 的服务：主对话的事；新代码要重启后才生效。

## 4. 经验

- 副本里的旧任务只能看，测「对已处理任务做的事」要从真实录像剪片段、在副本里新建任务。已写进 `docs/04-维护手册.md`「在真实数据的副本上实测」。
- 按整份转录稿算版本，长录像的翻译只能一次交回，一次工具调用装不下；改成每页固定句子范围、各自的版本。已写进决策 4.16。
- `tests/test_agent_surface.py` 把 `SKILL.md` 里反引号包着的下划线名字当工具名核对，写返回字段名时不加反引号。只关这个项目，写在这里。
- 实测数字（一次测量，机器同时在跑别的测试）：150 秒的视频读画面字幕约 40 秒；全量测试并行约 95 秒，负载 48 时 14 分钟。
- 跨项目：交来的任务里写了「在某种副本上实测」，动手前先确认那种副本允许这种操作，不行就换一个能测到同一条路的办法，并在交付里写明换了什么。
