### 4. 经验

- 产出文件夹被挪到别处后（他把读完的挪进「学习资料」），在编辑页或接口改转录稿只更新任务里的文件，产出文件夹不跟着变：这是设计好的「挪走不重建」（决策 6.11「意外情况」一条，`backend/core/output_folder.py` 日志写「产出文件夹不在原来的位置了」），这次是手动把字幕文件拷过去的。落点：已有决策，不另记；改转录稿时记得检查产出文件夹在不在原处。
- 画面字幕里夹着 UP 主加的括号注释（「MLA（Multi-head Latent Attention…）」「10B 的（激活）模型」），不是口播。拿画面字幕当参照要先去掉；画面字幕修正（4.10）是让模型只换听错的词，应该不会把注释抄进转录稿，没核实。落点：测试记录 `对比表.md`「怎么算的」；4.10 要不要加一道检查，转给主对话判断。
- 托管版 `.env` 里的 DashScope Key 已失效，ElevenLabs 那把只开了语音转文本，后来他加了「用户」读权限。落点：决策 4.11。
- 跨项目：替用户改第三方平台 API Key 的权限，浏览器自动化会被安全机制拦下（两次都拦），直接给他步骤让他点更快。
- 跨项目：后台跑的 Python 脚本 `print` 被缓冲，日志一直是空的，看不出进度；后台脚本用 `python -u`。
