# 让 agent 替用户装好、用起来（2026-10-11 定）

## 目标

FluentFlow 只做本地版。用户把仓库链接交给自己的 agent（Claude Code、Codex 等），说一句「帮我装上」，之后人不需要再动手：不输密码，不点系统弹窗，不申请 API Key。

判断一步该不该留给人：只看 agent 能不能代做。对人繁琐、对 agent 只是多几条命令的步骤照常保留。agent 代做不了的有三类：输电脑密码、点系统弹窗、注册账号和付钱。

## 要做的三件事

### 一、让用户的 agent 写笔记，不需要 API Key

用户已经在为自己的 agent 付费，笔记交给这个 agent 来写，FluentFlow 本身不再要求配置模型 Key。

- 加一个取材料的工具：给 agent 一个任务的转录稿（带时间点）、截图（文件路径和时间点）、当前生效的笔记 skill（用户自己的，没有就用默认），以及代码里固定的输入输出要求。
- 加一个存笔记的工具：agent 写好的笔记存回任务，成为这个任务的笔记，旧笔记照常可以恢复；记录这份笔记由 agent 写成。
- 提交视频和链接的工具在没有配置 Key 时照常完成转录，并在结果里告诉 agent 接下来用上面两个工具写笔记。
- 产品界面里没有配置 Key 时，写笔记的入口说明「让你的 agent 来写」，并给出可以直接复制给 agent 的一句话。
- 配置了 Key 的用户，现有写法不变。
- 笔记测评集也要在这条路上跑：同一批录像，由 agent 按同一份 skill 写，和产品自己写的并排比。

笔记质量这时取决于用户的 agent 用的是什么模型，skill 能约束写法，约束不了模型能力。

产品里已有用 Claude Code 登录写笔记的通道，目前只在维护者本机开启。第三方产品借用用户的订阅登录是否被 Anthropic 允许尚未核实，核实之前不作为主路。

### 二、安装过程不需要密码和弹窗

现在的安装要用 Homebrew 补 FFmpeg、Node.js 和 Python，装 Homebrew 要输密码；全新 Mac 第一次运行 git 会弹窗要求装开发者工具。改成：

- Python：用不需要管理员权限的方式装到用户目录。
- FFmpeg：下载现成的程序文件放进数据目录，不经过包管理器。
- Node.js：前端界面在发布时就构建好，放进发布包，用户机器上不再构建，也就不需要 Node.js。
- 代码：从 Releases 下载压缩包，不用 git。
- 转录模型：下载失败时自动换国内镜像，不需要人设置。
- Windows：核实 winget 安装各依赖时会不会弹管理员授权，会弹的换成同样不需要授权的方式。

改完后在一台全新的 Mac 和一台全新的 Windows 上各实装一次，确认全程没有任何需要人点或输入的地方。

### 三、给 agent 的安装说明

仓库根目录放一份专门写给 agent 的安装说明，README 第一屏指向它。内容：

- 按顺序执行的安装步骤，每一步怎么判断成功、失败了怎么处理。
- 最后用 `scripts/check_local_readiness.py` 验收，全部通过才算装好。
- 装好后怎么接上 FluentFlow 的 MCP 工具，以及第一次怎么替用户写一篇笔记。
- 遇到确实需要人的情况（例如磁盘不够），agent 应该怎么跟用户说。

推给别人时只需要一句：「把这个链接发给你的 Claude Code 或 Codex，让它帮你装上。」

## 顺序

1. 先做第一件，它去掉的是唯一既要人动手、又要花钱的一步。
2. 再做第二件。
3. 最后按改完的流程写第三件，写完用一个干净的 agent 照着它实装一次验收。
