# 流程账本

记每条流程规矩有没有用。规矩也会漂：加着加着全是检查，真正拦住东西的没几条，最后大家开始绕。靠感觉改规矩就是碰运气，所以这里只记能数出来的东西。

| 规矩 | 防什么错 | 最近生效 | 生效次数 | 结论 |
|---|---|---|---|---|
| 任务卡 | 换会话后范围和验收丢失 | | 0 | 留 |
| 验收命令绑定 | 「我看过了应该没问题」 | | 0 | 留 |
| 独立审查（只看卡和 diff） | 顺着作者思路放过同一个错 | | 0 | 留 |
| 合并前集成检查 | 各自单测过、合起来炸 | | 0 | 留 |

## 怎么记

- 「最近生效」写日期，指这条规矩真拦住一次错的那天；没拦住过就空着。
- 「生效次数」从任务卡的「结果」里数，不靠回忆。
- 结论三选一：留、改（写清改什么）、删。

## 什么时候删

- 一条规矩连续 10 次没拦到东西，删。
- 一个检查连续 5 次误报（拦下的都是没问题的），改或删。
- 删掉的规矩在账本里留一行，写明哪天删的、为什么，不写进决策记录。

## 每月看一次

十分钟：翻这批卡的结果，更新账本，最多改一条规矩。改之前先写下这次要看哪个数变好，下个月对。一次改两条就分不清是哪条起的作用，和一次只改一个变量是一回事。
