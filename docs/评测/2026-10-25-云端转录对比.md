# 云端转录对比：罗福莉 3.5 小时访谈（2026-10-25）

问题：本机转录把模型名、英文术语听错（GLM-5 写成 GOM、loss spike 写成 Northback），笔记里因此很多「（存疑）」。换成云端语音识别，能不能从源头把这些词识别对。

做法：同一条剪后视频（3 小时 23 分）整条交给四种云端识别各跑一次，和本机原样转录稿比。参照答案有两份：画面上烧录的字幕（本机文字识别读出，挑出 78 个术语、共 926 次出现），和王愉超在笔记里纠正过的 22 处。完整过程、原始结果和统计脚本在 `~/Downloads/FluentFlow测试记录/2026-10-24-234903-云端转录对比/`，总表在其中的 `对比表.md`。

- ElevenLabs 最准，也只写对一半专有名词。qwen3-asr 第二，但大文件版只给 60 秒一块的时间，做不了字幕、剪气口和笔记时间戳。fun-asr 只比本机好一点。
- 热词只对列进去的词有效：标题和章节栏里的「罗福莉」「张小珺」「OpenClaw」加进去就写对了，整体比例没变。转录前能拿到的词只有这十来个。
- 有一批词所有引擎都错：OpenClaw 写成 OpenCloud，Claude 写成 Cloud，MLA 写成 MA，GLM-5 写成 GOM 或 Gem5，loss spike、norm、Miclaw、Kron、MiniMax、long context efficient 也是。换哪家识别都修不了，画面上的字幕能修（决策记录 4.10）。
- 每家只跑了一次。挑术语和「算对」的规则见测试记录的 `对比表.md`「怎么算的」一节。

## 建议

不把云端识别设成默认。有画面字幕的视频，按画面字幕修正（4.10）不花钱、不上传，修的正是云端也修不了的那批词。没有画面字幕、术语又密的录像，可以给一个可选项「用 ElevenLabs 转录」：比本机多对约四分之一的术语，代价是音频传到美国、按时长付费、长录像要等得更久。fun-asr 和 qwen3-asr 不值得接。接不接、怎么接，等王愉超定。
