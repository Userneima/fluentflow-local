## 这几次提交新带出来的半截

1. **决策 4.9 说「Claude、agent、文字模型三条路一起改」，文字模型有两条路其实用不上这条规则。**真名规则只在 `speaker_labeled` 时拼进提示词，而网页和 agent 的文字模型重写不传说话人标号（`local_note_regen.py:170`，`local_agent.py:1066`），也不带校正文档；一小时以上的录像走按章写，校正文档进不去逐章写（`ai_summarizer.py:1166-1167`）。这几条路上会议待办仍然只能写「说话人 B」。依据：`docs/02-决策记录.md:549`。和第 2、6 条一起修。
2. **权限报错的提示只按 macOS 写，Windows 上也会显示。**bdccd7d 新加的「没有权限读写这个文件」让人去「系统设置 → 隐私与安全性 → 完全磁盘访问权限」、把文件挪到「影片」「文稿」，没有按系统区分：`local_error_diagnostics.py:555`，`format.js:440`。Windows 上出现 permission denied 时，这句话没法照做。
3. **导出失败的新提示让 agent 用 `debreath_task` 重新剪，新流程的任务会被拒。**`local_error_diagnostics.py:240`（bdccd7d 加的）；`debreath_task` 对先通查再剪的任务一律返回 409（`local_job_debreath.py:95-103`，即第 7 条）。前半句「处理说明里点任意一处改判」能用，后半句不能。
4. **改笔记规则的版本检查默认不生效。**dee3acd 给 `apply_note_rule` 加了 `base_version`，但它是可选参数（`fluentflow_mcp_server.py:1383`，没进 `required`），而 agent 照着做的 `agent/skills/fluentflow/SKILL.md:49` 没提要带它。照 SKILL.md 做的 agent 不会传，用户在设置里改的规则仍会被 agent 整份盖掉（历史里能找回）。决策 6.17 写的是「可以带上」，口径和防覆盖的初衷不一致。
5. **README 新写的「码率高的录像另有一份不剪的压缩版」，在 Windows 上不成立。**`README.md:120`（551024f）；压缩只认 `hevc_videotoolbox`，没有就跳过（`compress_media.py:123-124`，即第 8 条）。README 同一段也没说产出文件夹里的字幕、转录副本改了不会收回，被改过的会另存成「_我的修改-时间」（`output_folder.py:356`）。按 94149dd 刚加的 AGENTS.md 规则，这两处都该在同一次推送里写对。
