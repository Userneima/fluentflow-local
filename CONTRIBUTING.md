# Contributing

欢迎提交问题报告（issue）和使用讨论：请附上复现步骤与环境信息，不要包含
用户数据、密钥或私有运行记录。

本仓库目前**不接受代码 Pull Request**：这里的代码由上游经导出流水线生成，
PR 无法直接合并。功能建议和缺陷报告都会在上游处理后随版本同步到这里。

Issues and discussions are welcome. Code pull requests are currently not
accepted: this tree is generated from an upstream source via an export
pipeline, so PRs cannot be merged here. Bug reports and feature requests
are triaged upstream and land here with each release.
