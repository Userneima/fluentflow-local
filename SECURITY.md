# Security

发现安全漏洞请通过 GitHub 的私密漏洞报告提交（仓库 Security 页签 →
"Report a vulnerability"），不要开公开 issue 描述漏洞细节。

Please report vulnerabilities privately via GitHub's private vulnerability
reporting (Security tab → "Report a vulnerability"); do not describe
exploitable details in a public issue.

报告或 issue 中请勿包含 `.env`、访问令牌、用户媒体、转录、笔记或运行数据库。
